# Sistema-OS

Aplicação single-file (HTML/CSS/JS) para gerenciamento de Ordens de Serviço de impressoras 3D.

Arquivos:
- `Sistema-OS.html` — aplicação principal (mobile-first).

Deploy rápido (GitHub Pages):
1. Crie um repositório no GitHub (público).
2. No diretório local:

```bash
git remote add origin https://github.com/<usuario>/<repo>.git
git branch -M main
git push -u origin main
```

3. Ative **GitHub Pages** em `Settings > Pages` (branch `main`, root).

Alternativas: Netlify, Cloudflare Pages.
